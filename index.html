Join the server

Want to play? It takes about 10 minutes the first time. You need a Minecraft: Java Edition account and the free CurseForge app.

narwhalman.com

No port needed. If the address ever changes, it will be updated here.

How to join

  1. Install the CurseForge app from curseforge.com/download/app and open it. Choose Minecraft.
  2. Import the pack. Click Create Custom Profile, then Import, and pick the zip you downloaded above. CurseForge sets up Minecraft 1.21.1, NeoForge and all the mods for you. The first install takes a few minutes.
  3. Give it memory. Open the profile's settings (the gear icon), find Allocated Memory and set it to 8 GB (8192 MB). If your PC has 16 GB or more it is fine to go a bit higher; with 8 GB of RAM or less in total, expect trouble.
  4. Press Play. The first launch is slow because of the 205 mods. Sign in with your Minecraft: Java Edition account when asked.
  5. Add the server. In the game choose Multiplayer, then Add Server. Paste the server address from the box above, press Done, then double-click the server.

If something goes wrong

  • "Mismatched mod list", "incompatible" or it won't connect: your pack is out of date. Download the latest pack from this page and import it again as a new profile.
  • The game crashes on start or says it is out of memory: raise Allocated Memory in the CurseForge profile settings (try 10 GB), and close other programs.
  • "Failed to authenticate" or "invalid session": restart the launcher and sign in again. The server needs a genuine Java Edition account; offline or cracked accounts can't join.
  • A mod can't be downloaded during import: try the import again; if it still fails, tell Narwhalman_Op which mod it names.

Check your download is intact (optional): its SHA-256 should start 72cbf75f and end 71e72460.

Overview

Narwhal Revelations takes a hand-modified Beyond Mines: Revelations II 1.2.1 server (Minecraft 1.20.1, Forge 47.3.0, 210 mods) and rebuilds it for Minecraft 1.21.1 on NeoForge 21.1.265. Every mod that has a NeoForge 1.21.1 build is in. Seven mods that only have unofficial community ports are in as well. The rest are listed with reasons in Missing mods.

Mod count

205 jars: 176 of the 210 original mods from CurseForge, 7 more that are Modrinth-only, the 7 community ports (6 CurseForge, 1 Modrinth), 14 libraries and 1 helper mod. 180 run on the server, 25 are client-only.

Two downloads

A CurseForge import pack (197 CurseForge files plus 8 Modrinth jars as overrides) and a server pack with a launcher, configs and scripts.

Tested

The server pack was unzipped fresh, installed on Java 21 and booted to Done with a new world and no crash. All 10 KubeJS scripts loaded with 0 errors and 0 warnings. Nothing was played in game.

New world

1.20.1 worlds do not load on 1.21.1. The pack starts a new world; the original terrain seed will not give the same map.

Every CurseForge file was checked to carry the NeoForge and 1.21.1 tags and was the newest release (a beta or alpha only where no release exists; see Caveats). Required dependencies were read from each jar and resolved. All CurseForge project and file ids in the manifest were checked against the CurseForge API.

How it differs from BM Revelations II 1.2.1

The source server is the official 1.2.1 pack plus a tech and magic layer: 55 mods added, 23 removed, 3 updated, and 16 client-pack mods kept on the server. It also carries 7 active KubeJS scripts and a handful of hand-edited configs. The baseline is the official 1.2.1 server pack (CurseForge file 5715118) plus the 1.2.1 client manifest (file 5715089); mods were matched by mod id read from each jar, not by file name.

A small datapack that adds 5 extra XP to every experience orb ships in the server pack as world/datapacks/DoubleExp (pack_format 48). Known caveats

  • Fresh world needed. Worlds from the 1.20.1 server do not load on 1.21.1. Player data, FTB teams and quests, advancements and stats are not carried.
  • Beta and alpha builds. 13 mods are in the pack as a beta or alpha because no release exists for 1.21.1 (table below). CC: Tweaked is alpha on every 1.21.1 NeoForge build.
  • modernfoundry ids. The Tinkers port does not use tconstruct: ids, so Tinkers add-ons (such as Tinkers' Better Combat) and old recipes do not apply.
  • Unofficial ports. Seven mods are community ports. Expect rough edges and report issues to those projects.
  • Eight jars are Modrinth-only. They sit in the import pack's overrides/mods folder, so the pack can be imported into the CurseForge app but cannot be published as a CurseForge modpack.
  • Not tested in game. The boot test covers loading, scripts and datapack functions. Waystones cooldown and unbreakable rules, the Ars Nouveau tome check in test.js and gameplay balance were not exercised with a real player.
  • Waystones restrictToCreative is only partly carried. There is no creative-only switch in 1.21.1; generated waystones can only be edited by players with the edit-all permission.
  • Not carried: the CommonCapabilities $.energy entry (its 1.21 option works per data component), and client preferences such as JEI list sizes and the Oculus shader choice.
  • Harmless console noise. A few loot tables of Create: Enchantment Industry and Extra Disks name unregistered items, two Curios slot names are unregistered, four Medieval Buildings tags miss references, and Ice and Fire CE and Jupiter log a missing config file on the very first start. These come from the mods themselves.

Install

Players: CurseForge app import

  1. Download Narwhal_Revelations-1.1.0.zip (see Join the server for the short version).
  2. In the CurseForge app, open Minecraft, choose Create Custom Profile and then Import, and pick the zip. Other launchers that read CurseForge manifests can import it as well.
  3. The app installs Minecraft 1.21.1, NeoForge 21.1.265 and the CurseForge mods. The 8 Modrinth jars come from the zip itself.
  4. Give the game 6 to 8 GB of RAM or more; the pack has 205 mods.
  5. Join a server running the matching server pack, or start a new single-player world.

Server hosts

  1. Install Java 21 (for example Eclipse Temurin 21) and check java -version.
  2. Unzip Narwhal_Revelations_ServerPack-1.1.0.zip into an empty folder.
  3. Run start.bat or start.ps1 (Windows) or start.sh (Linux, macOS). The first run installs NeoForge 21.1.265 and starts the server.
  4. The server stops straight away and writes eula.txt. The Minecraft EULA is not accepted for you. Read aka.ms/MinecraftEULA and, if you agree, set eula=true, then start again.
  5. Memory is set in user_jvm_args.txt (-Xmx15G -Xms15G). Lower it if the machine has less RAM.
  6. A new world is generated. Open the server's network port only as needed and manage ops and the whitelist yourself; no player lists are included.

The pack's server.properties sets difficulty hard, spawn-protection 0, view-distance 16, simulation-distance 10 and enforce-secure-profile true. Edit it freely. PORTING_NOTES.md and MISSING_MODS.md are inside both zips.
